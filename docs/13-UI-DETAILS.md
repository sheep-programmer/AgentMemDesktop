# 导入与日常操作的细节改进

日期：2026-10-03。继续完善表单提示、错误恢复、触屏与键盘操作。

## 资料导入

- 本地文件、粘贴文本、网页链接保留为三个标签；输入框使用明确标签与帮助文字，焦点可见。窄屏弹窗留出边距，并可在较矮窗口中滚动。
- 文件导入提供独立“选择文件”按钮，保留拖放。弹窗在上传前检查单文件 100 MB 上限，与后端现有上限一致；格式仍由后端解析器决定。
- 逐项列出未导入文件及原因。部分成功时更新资料列表并保留失败清单，不再马上关闭弹窗隐藏结果。
- 网页地址只接受完整的 HTTP / HTTPS URL，错误出现在输入框下方；无效地址不会发起请求。登录后才可见的网页提示用户使用文本导入。
- 文本失败时保留当前草稿，可以修改后重试；支持 Ctrl / ⌘ + Enter 提交。文本默认标题使用可读的日期。
- 同一弹窗的三种方式共享同步提交保护。关闭、换空间或卸载后，旧响应不能关闭新弹窗或发布旧结果。

关闭弹窗不等于取消服务器已经受理的导入，也不回滚资料。本轮没有更改后端摄取、URL 访问限制或文件格式能力。重新打开后应以资料库刷新得到的状态为准。

## 历史对话与资料卡片

- 历史对话的重命名、置顶与删除集中到常驻操作菜单；菜单内容带文字，删除保留既有确认。触摸目标为 36 像素。
- 选中对话带 `aria-current`，已置顶有标记；菜单操作不会误触打开对话。重命名保留 Enter 保存、Escape 取消与输入法组字保护。
- 新建对话增加同步防重复与创建中提示。加载、搜索和无结果使用不同文案。
- 资料卡片的勾选框和菜单常驻可见，点击区增大，并提供键盘焦点样式。
- 已就绪、失败、处理中分别展示对应状态。只有收到后端进度时展示百分比，不再用固定 25% / 65% 估计进度；处理中不允许再次触发解析。
- 通用加载视图增加可读的状态公告，装饰性骨架不参与朗读；失败状态明确提示暂时无法加载，并保留重试入口。

## 验证

新增 12 项交互回归：无效链接不发请求、合法链接参数、文本失败保留与重试、重复提交与关闭后旧结果失效、部分文件失败、大小限制、会话操作不误选、重命名只提交一次、重命名焦点与取消、新建防重复、加载完成切换和错误重试。菜单关闭时将焦点交给标题输入框，编辑中的 Enter / Escape 不再传播到外层抽屉。

前端完整 193 项测试、38 个测试文件通过；类型检查、lint、生产构建通过。六页深浅主题及设置标签、会话操作菜单、导入的三个标签和 URL 错误状态对比度通过。构建仍保留部分按需资源超过 500 KB 的提示。

浏览器 使用示例数据检查 390 像素窗口：导入弹窗和会话菜单无横向溢出，重命名输入保持焦点，Enter 保存后显示新标题，Escape 取消后原名仍在且历史抽屉保持打开。验收后恢复示例标题，没有改动真实知识空间或调用真实模型。
