# 更容易理解和操作的界面

日期：2026-10-03。检查六个页面后，优先改进聊天、反馈、备份和用量说明。保留原有业务流程、主题与检索配置。

## 改进

| 使用场景 | 原来的障碍 | 现在的行为 |
| --- | --- | --- |
| 查看回答进度 | 四阶段长链条在窄屏被截断；生成开始时自动展开挤占回答区域 | 先显示当前步骤，如“正在查找相关资料”；用户打开详情才查看阶段卡片 |
| 回答停止或读取历史 | 失败仍可能呈现普通流程，历史消息没有执行中的阶段 | 明确区分停止、未完成、完成与历史生成记录；保留检索受限提示 |
| 操作一条回答 | 桌面上按钮只在悬停时出现，图标用途要猜 | 常驻文字操作：复制、再答一次、有帮助、不满意、纠错；支持键盘与触摸 |
| 复制失败 | 未等待剪贴板结果，失败时仍显示“已复制” | 只在写入成功后显示成功；失败时提示手动复制，离开页面时清理提示计时器 |
| 提交纠错 | 文案容易让人以为已经成为有效经验 | 明确说明是待学习素材，验证后的经验才会生效；操作为“保存纠错” |
| 下载或恢复备份 | 长按钮、技术统计说明混在一起，恢复后没有明确下一步 | 两张独立操作卡；恢复后刷新空间列表与统计，并提供进入知识空间的入口 |
| 备份或统计失败 | 错误主要靠短暂通知，统计没有重试入口 | 页面保留错误提示；可以刷新或再次选择文件重试 |
| 查看模型用量 | 固定缓存折扣被呈现成费用估算，技术字段过多 | 显示输入、输出和服务商报告的缓存复用；实际折扣与费用以服务商账单为准 |
| 切换资料视图 | 小尺寸纯图标，选中态没有可访问语义 | 36 像素按钮、有名称和单选状态，支持键盘焦点 |

恢复备份不会覆盖已存在的空间。导入操作仍由后端完成；本次没有增加取消恢复或回滚功能。页面任务归属用于阻止重复提交与离开后更新旧页面，不表示后端写入已撤回。

用量页移除了统一按 0.1 倍单价推算的费用降幅。第三张卡改为实际输出量；没有增加服务商定价表或自动计费功能。缓存量仍包含在输入量中，两者不重复相加。

## 验证

- 前端全量 181 项测试通过，35 个测试文件。资源繁忙时的并发超时通过限制测试 worker 后复核，没有上调断言超时。
- 新增 10 项交互回归：进度详情、停止状态、检索受限、历史记录、具名回答操作、复制失败、纠错语义、统计重试、恢复后入口及失败后重试。
- 类型检查、lint、生产构建通过。生产构建仍保留部分按需资源超过 500 KB 的警告。
- 六页深浅主题、已有弹层与设置页全部标签对比度通过。导入资料弹层改为必检，并按出现状态等待。
- 浏览器 使用示例数据检查；390 像素窗口的聊天、反馈和备份页面无横向溢出。反馈按钮高 36 像素，备份操作高 40 像素。
- 恢复后的空间列表与导航由 mock 服务单元测试验证。没有修改真实知识空间，没有调用云端模型；本轮没有改后端或重新进行真实模型质量评测。
