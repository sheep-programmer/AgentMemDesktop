# 长任务取消、并发与异常恢复

日期：2026-10-02。覆盖知识进化、考题生成、评测与检索配置对比的长任务生命周期。

## 行为变化

| 场景 | 当前行为 |
| --- | --- |
| 同一空间重复启动同类任务 | 后端拒绝重复任务，返回流内 `SPACE_LOCKED`；前端在确认与执行期间也阻止重复提交 |
| 长任务执行中启动空间维护 | 任务持有共享写入许可，维护不能在模型生成或清理尚未结束时取得互斥许可 |
| 切换页面或知识空间 | 中止流式请求，旧任务的阶段、结果和完成回调失效 |
| 手动停止 | 进化、评测、出题与配置对比都有停止操作，按钮恢复后可以重新启动 |
| 旧请求晚于新请求结束 | 旧任务不能发布成功、修改新任务进度或清除新任务的运行状态 |
| 流结束但没有完成结果 | 显示连接中断提示并恢复操作，不将 EOF 当成完成 |
| 错误之后收到迟到的完成事件 | 终止状态只接受一次，不再展示成功摘要 |
| 对比弹窗运行时关闭 | 关闭会取消请求，不再因运行状态将用户困在弹窗内 |
| 停止后存在部分结果 | 页面保留提示，提供刷新入口；已保存的候选经验、考题和方案记录不回滚 |

## 实现

共享 `OperationGate.activity()` 按空间与操作名称保护任务。“进化”覆盖蒸馏、合并和完整闭环；“评测”覆盖单轮、配置对比和经验归因；出题和一致性测算分别使用自己的操作名称。不同名称的任务仍可以并行，这不是所有业务操作的全局串行锁。

SSE 响应持有许可直到底层生成器完成清理，正常完成、异常和断开都会退出作用域。完整进化流同时显式关闭内层闭环生成器，避免外层取消后内层继续占用资源。

前端 `useAsyncTask` 将请求归属绑定到当前空间、组件生命周期和本次运行。启动同步登记，停止或卸载会中止 `AbortSignal`；只有当前运行才能更新页面。演示服务同样使用可取消延迟，服务层无需依赖 React Hook。

有限任务流明确要求 `done` 或业务 `error` 作为终止事件。普通摄取订阅维持已有长连接语义。连接关闭前没有收到终止事件时，传输层返回 `INCOMPLETE_STREAM`，页面保留错误提示和刷新入口。

进化的测验题预检查使用独立任务归属；离开页面后忽略结果。它是短时读取，当前没有给这个读取请求新增取消参数。

备份下载将 Blob URL 的释放延迟一秒，给浏览器启动下载留出时间；这项调整只涉及下载资源的生命周期。

## 界面与验证

- 进化区区分“检查测验题”和实际运行，提供停止按钮与持久状态提示；示例素材计数与确认内容一致。
- 评测与出题避免在同一界面同时启动，停止和断流提示带有可访问的 `status` / `alert` 语义及刷新入口。
- 对比弹窗头部支持窄屏换行，运行时可停止或关闭；去掉整块进度区的闪烁效果。
- 对比度回归新增测验题标签、对比弹窗、运行和停止状态。修正深色基准方案徽章的背景后，六页深浅主题及相关弹层均达到正文 4.5:1 / 大字 3:1。
- 评测历史有独立刷新入口，停止或关闭对比后可确认已保存的方案；读取失败时明确提示重试。

浏览器确认进化停止后重新运行并完成、评测停止、切页后不再出现旧评测完成提示，以及配置对比停止。390 像素窗口下，对比弹窗没有横向溢出。页面截图见 [进化阶段](previews/evolution-completed.png) 与 [窄屏停止提示](previews/comparison-stopped-mobile.png)。

新增 5 项后端、20 项前端回归，覆盖重复启动、维护冲突、流清理、EOF、终止事件、卸载取消、停止与重新启动，以及旧结果失效。

浏览器验收使用示例数据；后端测试使用临时数据与 mock 模型。没有修改真实知识空间或发起云端模型请求。构建仍有部分按需资源超过 500 KB 的提示。

这轮完善的是本地单进程应用的任务生命周期与维护保护；不会撤回已落盘结果，也不保证远程模型提供方撤销已受理的请求。中断后应以刷新得到的资料和评测历史为准。

```bash
uv run ruff check .
uv run ruff format --check .
uv run mypy
uv run pytest -q

cd apps/web
pnpm typecheck
pnpm lint
pnpm test:run
pnpm check:contrast
pnpm build
```
